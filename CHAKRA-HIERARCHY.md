# Chakra hierarchy mapping

The hierarchy preserves the [HackMD outline](https://hackmd.io/21uN7y70SPOLKgK_mYZ-mA) and incorporates the additional associations requested in this project. Chakra associations are the project's custom grouping. TA98 is used to identify anatomical branches and organs, without changing Systems.

Structure links open selected anatomy in a model containing it. Broad system links show the relevant layers, and chakra links open the Chakras tree. All viewer links use `http://localhost:3016/`.

- Cervical nerves map to Vishuddha; brachial branches map to Anahata. Upper, middle and lower thoracic levels follow the outline, with T6 shared. Unnumbered intercostal meshes are shared across the thoracic groups rather than given an invented segment number.
- Lumbar nerves map to Swaddhishtana. Sacral/coccygeal and pelvic branches are shared with Muladhara. Unspecified spinal roots and ganglia have an explicit group in Muladhara.
- Anatomical descendants use the TA98 ancestry, named peripheral plexuses, and directed atlas `after`/`contains` nerve relationships. Known TA98 peripheral ancestry takes precedence over incorrect source collection tags such as “Central nervous system.” Source spelling variants and unnamed segment bundles are retained.
- Modeled `innervates` targets are included in the same chakra as their nerve. TA98 descendants and all material meshes of an organ follow the organ. Original plexus associations are retained.
- The organ association list also includes the [diaphragm](http://localhost:3016/?model=male-detail&tree=guest%3Achakras&select=ZA%3ADiaphragm&context=0.18&skin=0.1&focus=1) for phrenic nerves, and pharyngeal/laryngeal, thoracic and abdominal organs associated with vagus. Pelvic/urinary/reproductive organs follow the pelvic groups.
- A whole-organ mesh is selected as a whole. For example, a [transverse-colon mesh](http://localhost:3016/?model=male-detail&tree=guest%3Achakras&select=ZA%3ATransverse+colon&context=0.18&skin=0.1&focus=1) cannot express only its proximal vagal territory. The list of modeled functional relations is limited by the atlas relation table; this hierarchy does not add geometry or a complete physiological innervation database.

Anatomical references: [OpenStax peripheral nervous system](https://openstax.org/books/anatomy-and-physiology/pages/13-4-the-peripheral-nervous-system), [autonomic divisions](https://openstax.org/books/anatomy-and-physiology-2e/pages/15-1-divisions-of-the-autonomic-nervous-system), [cranial nerves and hearing](https://openstax.org/books/anatomy-and-physiology-2e/pages/16-3-the-cranial-nerve-exam), and the project's existing TA98 concordance and anatomical relation table.

## Files and rebuilding

- `scripts/chakras-outline.json`: original outline, including labels for anatomy/hormones without geometry.
- `scripts/build-chakra-hierarchy.mjs`: builds explicit bilateral anatomy-name lists from all catalogues present under `public/models` and `.local-models`.
- `public/assets/chakras.json`: deployable hierarchy; edit the outline or builder and regenerate this file.
- `dist/assets/chakras.json`: generated by the production build.

```sh
npm run build:chakras
npm run test:chakras
npm run check
npm run build
```

The generation step computes nerve relationships offline. The viewer performs indexed name lookups; it does not traverse innervation relationships while opening Chakras or entering VR. Explode assigns overlapping anatomy to its first matching chakra and never duplicates a mesh.

## Verification

`npm run test:chakras` checks eight non-cell catalogues in this checkout, including legacy and local models: 22,621 available catalogue mesh instances, 802 spinal/vagus concepts, and 1,314 modeled innervation links. Counts include repeated anatomy in different catalogues. It independently checks all 31 spinal levels on both sides, requested system memberships, inner-ear/hearing coverage, the exact `Other` complement, and mesh uniqueness/finite positions in the detailed model's Explode layout. Cell-model components are outside this macroscopic scheme.
