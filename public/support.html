Support

Human Atlas is maintained by Christian Tzurcanu.

Open a support issue on GitHub for viewer problems, incorrect anatomy, MCP connection failures or privacy questions.

Useful information to include

Describe the problem, the selected model and structure, your browser and the steps to reproduce it. Include an error message or a screenshot after removing private information.

GitHub issues are public. Do not include patient records, private conversations, credentials, session invitation codes or identifying medical information.

Connecting the public MCP server

Endpoint: https://human-atlas-connect.ctzurcanu.workers.dev/mcp
Authentication: No Authentication.

The public tools are search_anatomy, get_anatomy_options and show_anatomy. Local-only anatomy models are not available through this endpoint.
